## 0.1.0 (2026-10-23)

- Add the `worth-using` skill: a six-criterion usefulness rubric (Job, First value, Fit, Outcome, Trust, Return) where every rating carries its evidence (Claimed, Seen, Repeated), two zones (stranger-ready, worth using), and two modes: Score and Coach.
- Add team scoring: independent ratings before any reveal, the spread kept, and the rating backed by the strongest evidence reported, ties going to the lower rating. Never an average.
- Add Coach mode: an opening read of the builder, five bounded passes (Name the user, Watch the first ten minutes, Break it on purpose, Say what changed, Check for return), subtract-before-add, an exit rule, and two output cards.
- Add `references/rubric.md`: criteria, evidence, zones, team scoring, opening questions, builder dimensions, teaching moves, diagnosis, card templates, and voice examples.
- Report the builder's growth as a jagged trace with labeled dips, never a smoothed curve.
- Package the repository as the `worth-using` Amplifier bundle with the `/useful` mode and the staged `worth-using-round` recipe.
- Add a fictional worked run and the benchmark plan. The benchmark has not been run.
- Add a static explanatory site in the Amplifier Smart Tools family theme, with an in-browser scorer that stores nothing, and a checked GitHub Pages workflow.

- Added a complete portable install with MIT notice and conflict-preserving local installer; retained the canonical method and independent evidence dimensions.
