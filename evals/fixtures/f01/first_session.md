# First session and observation record

**FICTIONAL evaluation dossier. This is a scripted scenario, not a real user study.**

Participants: Mara Bell (the intended user, outside the builder's team), Jo Reed (independent session observer, also outside that team), and the builder only where explicitly recorded. Mara has not previously used TrayCount. The session uses Mara's normal consumables CSV.

[O01] (Fictional record date: 2026-08-31) Before opening the tool, Jo records Mara completing last week's restock list in 24 minutes using the stock spreadsheet. Mara: “Every Monday I subtract each count from its minimum and copy the positive amounts into the restock order.”

00:00 Mara opens her usual spreadsheet and selects Restock.
00:30 The program asks for `stock_profile`.
02:00 Mara reads the entire README.
04:00 Mara: “I don't know what the profile code is. My spreadsheet doesn't have one.”
08:00 Mara is still at the configuration screen. She tries no invented code and has no result.

[O02] (Fictional record date: 2026-08-31) At minute 10 Jo records that Mara cannot produce a first result alone because the required installation code is absent from the README and the interface.

[O03] (Fictional record date: 2026-08-31) At minute 14 the builder joins, writes `stock_profile=stage-stock-v1` into the config file, and leaves. Mara could not have derived this internal code from the supplied materials. This is the only help the builder gives. The persistent configuration is the only new setup item; all later work uses Mara's existing files and spreadsheet.

[O04] (Fictional record date: 2026-08-31) At minute 18 Mara independently previews her own CSV, checks all 12 rows against the manual calculation, and exports the correct restock list beside the input. Jo confirms that the original stock CSV is unchanged.

[O05] (Fictional record date: 2026-08-31) At minute 20 Mara runs a copy with `two` in a quantity cell. The tool names the row, produces no restock CSV, and leaves the original intact. Mara replaces the value with `2`, retries successfully, and then deletes the generated CSV to undo the trial. The builder is absent. Jo records each step.

[O06] (Fictional record date: 2026-08-31) Mara says without an outcome question: “I sent today's restock order without doing the twelve subtractions myself.” Jo compares the outgoing order with the checked preview and confirms they agree. This result followed assisted setup.

[O07] (Fictional record date: 2026-09-07) On the following Monday, Jo observes Mara independently generate and send the restock list in 5 minutes from the same spreadsheet and stock CSV. Mara: “I still collect counts the same way. Now I use the Restock command where I used to do the arithmetic.” No new account, data collection, or daily workflow is introduced. The one-time profile setup remains required for a new installation.

[O14] (Fictional record date: 2026-10-12) After week 6, Mara sends the independent observer an unsolicited note: “I opened it when Monday stock orders came due. Nobody reminded me. If it disappeared I would miss it because I'd be back to copying twelve calculations into the order.” The communication audit in this fictional scenario records no builder messages, posts, invitations, or reminders after the initial week-1 session invitation.
